Popify Bot - Privacy Policy

Effective Date: 03 December 2024 | Last Updated: 25 September 2025

1. Information We Collect

User IDs, Server IDs, message data (only when required), voice connection details, and usage statistics.

2. How We Use Information

  • To provide features (music, moderation, utilities).
  • To improve performance and fix bugs.
  • To prevent abuse or spam.
  • To comply with Discord’s policies.

3. How We Use Information

  • Feature Provision: To deliver and enhance features such as moderation, music, utilities, games, giveaways, and more.
  • Moderation & Security: To maintain server security, enforce rules, and prevent unauthorized changes or malicious attacks.
  • User Engagement: To personalize user experiences, manage role assignments, and provide automated responses to queries.
  • Service Improvement: To generate anonymous usage statistics and improve overall functionality.

4. Data Storage, Retention & Security

  • Data Retention: Data is retained only as long as necessary to provide services. Temporary data (such as message content) is stored only for the duration needed to provide features. Server settings are stored until you remove the bot or request deletion.
  • Security Measures: We employ encryption, access controls, and regular security audits to safeguard collected data.

5. Data Retention

Temporary data (queues, logs) is cleared after use. Server settings remain until reset or removal.

6. Data Deletion Request

Removing the bot from your server deletes stored settings. You may also request deletion anytime.

7. Security Measures

Encrypted databases, restricted developer access, and regular audits for safety.

8. Compliance with Discord Policies

We strictly follow Discord Developer Terms and Community Guidelines.

9. Compliance with Laws

We comply with GDPR and CCPA. Users under 13 are not allowed.

10. Communication

Updates may be announced in the support server. No spam or ads are sent.
